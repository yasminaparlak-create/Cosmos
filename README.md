# Cosmos
Вы управляете космическим кораблём в открытом космосе. Со временем сложность игры повышается, препятствия начинают падать быстрее. Ваша цель — выжить как можно дольше, уклоняясь от падающих объектов и набирая очки.  Игра бессюжетная, сфокусирована на рефлексах и выживании. 
#  Cosmos — Игровое приложение для Android

##  Техническая информация
- **Фреймворк**: LibGDX 1.10.0
- **Язык**: Java 17
- **Мин. версия Android**: 8.0 (API 26)
- **Разрешения**: 480×340 – 1920×1080 px
- **Размер APK**: ~12 МБ

##  Ключевые механики
- Бесконечный раннер с прогрессией сложности
- 4 уникальных скина корабля с сохранением выбора
- Система баффов: RAPID FIRE, SHIELD, EXTRA LIFE, SCORE BOOST
- Топ-5 рекордов с сохранением через Preferences + JSON

##  Оптимизация
- Object Pooling для пуль, препятствий и баффов
- Fixed Timestep для стабильной физики на любых FPS
- Векторная графика и шрифты для чёткости на всех DPI
- Корректный lifecycle для работы на устройствах с 512 МБ ОЗУ

##  Запуск проекта
1. Откройте проект в Android Studio / IntelliJ IDEA
2. Убедитесь, что установлен JDK 17 и Android SDK
3. Соберите APK: `./gradlew android:assembleRelease`
4. Установите на устройство с Android 8.0+
